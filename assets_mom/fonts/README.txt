Шрифты проекта (бесплатные, лицензия SIL Open Font License):

1. Manrope — https://fonts.google.com/specimen/Manrope
   Нужен файл: Manrope-VariableFont_wght.ttf (или статические Medium 500, SemiBold 600, Bold 700, ExtraBold 800)
2. Caveat — https://fonts.google.com/specimen/Caveat
   Нужен файл: Caveat-VariableFont_wght.ttf (или статический Medium 500)

Кнопка «Get font» → «Download all», из архива взять файлы выше и положить в эту папку.
Для Figma: шрифты установить в систему (или они уже есть в веб-версии Figma как Google Fonts), затем импортировать mockup-figma.svg.
